### 1 基本信息


| **项目** | **内容**                                   |
| ------ | ---------------------------------------- |
| 接口地址   | `pay-core/merchant/split/acctSplitBunch` |
| 请求方法   | POST                                     |
| 接口说明   | 对已完成的支付订单进行分账处理                          |
| 是否需要认证 | 是（需签名验证）                                 |


### 2 请求参数

#### 2.1 顶层参数


| **字段名**          | **类型**     | **是否必填** | **说明**     | **示例值**          |
| ---------------- | ---------- | -------- | ---------- | ---------------- |
| merchantNo       | String     | 是        | 商户号        | HZ123456789      |
| orderNo          | String     | 是        | 原支付订单号     | ORDER20251226001 |
| splitAmount      | BigDecimal | 是        | 分账总金额，单位：元 | 100.00           |
| acctSplitBunches | List       | 是        | 分账配置信息列表   | 详见下方             |


#### 2.2 acctSplitBunches 子参数


| **字段名**    | **类型**     | **是否必填** | **说明**    | **示例值**     |
| ---------- | ---------- | -------- | --------- | ----------- |
| merchantNo | String     | 是        | 分账商户号     | HZ987654321 |
| divAmt     | BigDecimal | 是        | 分账金额，单位：元 | 80.00       |


### 3 请求示例

```
{
  "merchantNo": "HZ123456789",
  "orderNo": "ORDER20251226001",
  "splitAmount": 100.00,
  "acctSplitBunches": [
    {
      "merchantNo": "HZ123456789",
      "divAmt": 80.00
    },
    {
      "merchantNo": "HZU567890123",
      "divAmt": 20.00
    }
  ]
}

```

### 4 响应参数


| **字段名** | **类型**  | **说明**                 | **示例值** |
| ------- | ------- | ---------------------- | ------- |
| code    | Integer | 响应码：0 表示请求成功，非 0 表示失败  | 0       |
| message | String  | 响应描述信息，失败时返回具体原因       | 成功      |
| data    | Object  | 业务数据，成功时为空对象，失败时为 null | {}      |


### 5 响应示例

#### 5.1 成功响应

```
{
  "code": 0,
  "message": "成功",
  "data": {}
}

```

#### 5.2 失败响应

```
{
  "code": 400,
  "message": "分账金额超过订单金额",
  "data": null
}

```
