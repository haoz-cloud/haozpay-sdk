## 1. 接口说明

用于商户向皓臻支付平台提交支付订单信息，发起聚合支付统一下单请求，获取支付凭证。

## 2. 请求信息

- **请求路径**：`pay-core/payment/order`
- **请求方式**：POST
- **签名验签：**需要

## 3. 请求参数

### 3.1 基础参数


|              |        |     |             |
| ------------ | ------ | --- | ----------- |
| 参数名          | 类型     | 必填  | 描述          |
| `merchantNo` | String | 是   | 商户编号        |
| `timestamp`  | Long   | 是   | 时间戳（毫秒）     |
| `bizBody`    | String | 是   | 业务参数JSON字符串 |
| `sign`       | String | 是   | 签名值         |


### 3.2 业务参数（bizBody内容）


|                     |            |     |                          |                                       |
| ------------------- | ---------- | --- | ------------------------ | ------------------------------------- |
| 参数名                 | 类型         | 必填  | 示例值                      | 描述                                    |
| `orderTitle`        | String     | 是   | 测试订单                     | 订单标题                                  |
| `orderAmount`       | BigDecimal | 是   | 0.02                     | 订单金额(元)                               |
| `payType`           | Integer    | 否   | 2                        | 支付类型 `枚举见：payTypeEnum`                |
| `useHaozPayCashier` | Boolean    | 是   | true                     | 是否使用皓臻支付收银台交易，必传true                  |
| `notifyUrl`         | String     | 是   | https://xxx.com/callback | 异步通知地址                                |
| `redirectUrl`       | String     | 否   | https://xxx.com          | 跳转地址                                  |
| `applySplit`        | Integer    | 否   | 0                        | 是否支持商户申请分账，不填默认为0`枚举见：applySplitEnum` |
| `expireTime`        | Date       | 否   |                          | 支付过期时间（不传则默认十分钟后取消）                   |


## 4. 请求示例

```JSON
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"redirectUrl\":\"https://xxx.com\",\"notifyUrl\":\"https://xxx.com/callback\",\"orderAmount\":0.02,\"orderTitle\":\"测试订单\",\"payType\":1,\"useHaozPayCashier\":true}",
  "sign": "generated_sign_string"
}
```

## 5. 返回结果

### 5.1 响应格式

```JSON
{
  "code": 0,
  "message": "success",
  "data": {
    "merchantNo": "商户编号",
    "channelType": "渠道类型", 
    "seqId": "请求流水号",
    "payType": 1,
    "orderTitle": "订单标题",
    "orderAmount": 0.02,
    "payInfo": "拉起支付信息",
    "merchantOrderNo": "商户订单号"
  }
}
```

### 5.2 data响应参数说明


|                   |            |                     |
| ----------------- | ---------- | ------------------- |
| +参数名             | 类型         | 描述                  |
| `merchantNo`      | String     | 商户编号                |
| `channelType`     | String     | 渠道类型                |
| `seqId`           | String     | 请求流水号               |
| `payType`         | Integer    | 支付类型                |
| `orderTitle`      | String     | 订单描述信息              |
| `orderAmount`     | BigDecimal | 订单金额                |
| `payInfo`         | String     | 拉起支付信息（链接根据打开环境自适应） |
| `merchantOrderNo` | String     | 商户订单号               |


## 6.枚举值

### `payTypeEnum`支付类型


|     |           |
| --- | --------- |
| 枚举值 | 描述        |
| 0   | 支付宝正扫     |
| 2   | 微信JSAPI支付 |


### `applySplitEnum`是否支持商户申请分账


|     |           |
| --- | --------- |
| 枚举值 | 描述        |
| 0   | 不支持商户申请分账 |
| 1   | 支持商户申请分账  |
