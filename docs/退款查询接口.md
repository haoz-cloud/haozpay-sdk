### 1. 接口说明

用于商户查询聚合支付退款订单的处理结果，获取退款状态及相关详情。

### 2. 请求信息

- **请求地址**：`pay-core/payment/refund/query`
- **请求方式**：POST
- **签名验签：**需要

### 3. 请求参数

#### 3.1 基础参数


|              |        |     |             |
| ------------ | ------ | --- | ----------- |
| 参数名          | 类型     | 必填  | 描述          |
| `merchantNo` | String | 是   | 商户编号        |
| `timestamp`  | Long   | 是   | 时间戳（毫秒）     |
| `bizBody`    | String | 是   | 业务参数JSON字符串 |
| `sign`       | String | 是   | 签名值         |


#### 3.2 业务参数（bizBody内容）


|           |        |     |     |       |
| --------- | ------ | --- | --- | ----- |
| 参数名       | 类型     | 必填  | 示例值 | 描述    |
| `orderNo` | String | 是   |     | 商户订单号 |


### 4. 请求示例

```JSON
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"orderNo\":\"ORDER123456\"}",
  "sign": "签名值"
}
```

### 5. 返回结果

#### 5.1 响应格式

```JSON
{
  "code": 0,
  "message": "success",
  "data": {
    "merchantNo": "HZ1971294971928846336",
    "orderNo": "ORDER123456",
    "refundSeqId": "REFUND20251020001",
    "paySeqId": "PAY20251020001",
    "payReqDate": "20251020",
    "refundAmount": 0.02,
    "actualRefundAmount": 0.02,
    "refundStatus": 2,
    "refundStatusDesc": "退款成功",
    "transFinishTime": "20251020153020",
    "feeAmount": 0.00,
    "acctSplitBunch": "{\"splitInfo\":[{\"merchantNo\":\"HZ1971294971928846336\",\"amount\":0.02}]}",
    "unconfirmAmount": 0.00,
    "confirmedAmount": 0.02,
    "payChannel": "T",
    "remark": "用户申请退款"
  }
}
```

#### 5.2 data响应参数说明


|                      |            |                              |
| -------------------- | ---------- | ---------------------------- |
| 参数名                  | 类型         | 描述                           |
| `merchantNo`         | String     | 商户号                          |
| `orderNo`            | String     | 商户订单号                        |
| `refundSeqId`        | String     | 退款请求流水号                      |
| `paySeqId`           | String     | 支付请求流水号                      |
| `payReqDate`         | String     | 支付请求日期                       |
| `refundAmount`       | BigDecimal | 退款金额                         |
| `actualRefundAmount` | BigDecimal | 实际退款金额                       |
| `refundStatus`       | Integer    | 退款状态 `枚举见：refundStatusEnum`  |
| `refundStatusDesc`   | String     | 退款状态描述`枚举见：refundStatusEnum` |
| `transFinishTime`    | String     | 交易完成时间，格式：yyyyMMddHHmmss     |
| `feeAmount`          | BigDecimal | 手续费金额                        |
| `acctSplitBunch`     | String     | 分账对象（JSON字符串）                |
| `unconfirmAmount`    | BigDecimal | 待确认总金额                       |
| `confirmedAmount`    | BigDecimal | 已确认总金额                       |
| `payChannel`         | String     | 交易通道`枚举见：payChannelEnum`     |
| `remark`             | String     | 备注                           |


## 6.枚举值

### `refundStatusEnum`退款状态


|     |     |
| --- | --- |
| 枚举值 | 描述  |
| 0   | 初始  |
| 1   | 处理中 |
| 2   | 成功  |
| 3   | 失败  |


### `payChannelEnum`交易通道


|     |       |
| --- | ----- |
| 枚举值 | 描述    |
| A   | 支付宝   |
| T   | 微信    |
| U   | 银联二维码 |
| D   | 数字货币  |
