## 1. 接口概述

该接口供商户分页查询挂靠订单列表，支持按订单号（模糊）、订单状态、创建时间范围等条件筛选，并需进行签名验签。

## 2. 接口信息


| **项目** | **内容**                                 |
| ------ | -------------------------------------- |
| 请求路径   | pay-core/payment/queryHostingOrderPage |
| 请求方式   | POST                                   |
| 签名验签   | 需要                                     |


## 3. 请求参数

### 3.1 基础参数（顶层）


| **参数名**    | **类型** | **必填** | **描述**        |
| ---------- | ------ | ------ | ------------- |
| merchantNo | String | 是      | 商户编号          |
| timestamp  | Long   | 是      | 时间戳（毫秒）       |
| bizBody    | String | 是      | 业务参数 JSON 字符串 |
| sign       | String | 是      | 签名值           |


### 3.2 业务参数（bizBody 内容）


| **参数名**     | **类型**  | **必填** | **示例值**       | **描述**                |
| ----------- | ------- | ------ | ------------- | --------------------- |
| orderNo     | String  | 否      | "ORDER123456" | 商户订单号（模糊查询）           |
| startTime   | Date    | 否      | "2026-01-01"  | 订单开始时间（格式：yyyy-MM-dd） |
| endTime     | Date    | 否      | "2026-01-31"  | 订单结束时间（格式：yyyy-MM-dd） |
| orderStatus | Integer | 否      | 2             | 订单状态（枚举值见 3.4）        |
| pageNum     | Integer | 否      | 1             | 页码（从 1 开始），默认值：1      |
| pageSize    | Integer | 否      | 10            | 每页大小（最大值：1000），默认值：10 |


### 3.3 请求示例

```
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"orderNo\":\"ORDER123456\",\"startTime\":\"2026-01-01\",\"endTime\":\"2026-01-31\",\"orderStatus\":2,\"pageNum\":1,\"pageSize\":10}",
  "sign": "generated_sign_string"
}

```

### 3.4 订单状态枚举（OrderStatusEnum）


| **枚举值** | **描述** |
| ------- | ------ |
| 0       | 待支付    |
| 1       | 支付中    |
| 2       | 支付成功   |
| 3       | 支付失败   |
| 4       | 已取消    |
| 5       | 退款成功   |
| 6       | 部分退款成功 |
| 7       | 退款中    |


## 4. 返回结果

### 4.1 响应格式

```
{
  "code": 0,
  "message": "success",
  "data": {
    "records": [...],
    "total": 100,
    "pageNum": 1,
    "pageSize": 10
  }
}

```

### 4.2 响应参数说明

#### 顶层响应参数


| **参数名** | **类型**  | **描述**      |
| ------- | ------- | ----------- |
| code    | Integer | 响应码（0 表示成功） |
| message | String  | 响应信息        |
| data    | Object  | 分页查询结果      |


#### data 节点参数


| **参数名**  | **类型**               | **描述** |
| -------- | -------------------- | ------ |
| records  | List<HostingOrderBO> | 订单列表   |
| total    | Long                 | 总记录数   |
| pageNum  | Integer              | 当前页码   |
| pageSize | Integer              | 每页大小   |


#### HostingOrderBO 订单对象参数


| **参数名**     | **类型**     | **描述** |
| ----------- | ---------- | ------ |
| orderNo     | String     | 订单号    |
| merchantNo  | String     | 商户号    |
| orderAmount | BigDecimal | 订单金额   |
| transAmt    | BigDecimal | 交易金额   |
| orderStatus | Integer    | 订单状态   |
| createTime  | Date       | 创建时间   |
| updateTime  | Date       | 更新时间   |
| reqSeqId    | String     | 请求流水号  |
| tradeType   | String     | 交易类型   |
| transStat   | String     | 交易状态   |
| payAmt      | BigDecimal | 支付金额   |
| endTime     | Date       | 支付完成时间 |
