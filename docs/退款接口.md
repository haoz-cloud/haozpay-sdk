## 1. 接口说明

用于商户向皓臻支付平台提交退款订单信息，发起聚合支付退款请求。

## 2. 请求信息

- **请求地址**：`pay-core/payment/refund`
- **请求方式**： POST
- **签名验签：**需要

## 3. 请求参数

### 3.1 基础参数


|              |        |     |             |
| ------------ | ------ | --- | ----------- |
| 参数名          | 类型     | 必填  | 描述          |
| `merchantNo` | String | 是   | 商户编号        |
| `timestamp`  | Long   | 是   | 时间戳（毫秒）     |
| `bizBody`    | String | 是   | 业务参数JSON字符串 |
| `sign`       | String | 是   | 签名值         |


### 3.2 业务参数（bizBody内容）


|                |            |     |                          |                       |
| -------------- | ---------- | --- | ------------------------ | --------------------- |
| 参数名            | 类型         | 必填  | 示例值                      | 描述                    |
| `orderNo`      | String     | 是   | 商户订单号                    | 商户订单号                 |
| `refundAmount` | BigDecimal | 是   | 0.02                     | 退款金额（元），单位元，需保留小数点后两位 |
| `refundReason` | String     | 否   | 退款原因                     | 退款原因                  |
| `remark`       | String     | 否   | 备注信息                     | 备注                    |
| `notifyUrl`    | String     | 否   | https://xxx.com/callback | 异步通知地址                |


## 4. 请求示例

```JSON
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"orderNo\":\"ORDER123456\",\"refundAmount\":0.02,\"refundReason\":\"用户取消\",\"remark\":\"测试退款\",\"notifyUrl\":\"https://xxx.com/callback\"}",
  "sign": "generated_sign_string"
}
```

## 5. 返回结果

### 5.1 响应格式

```JSON
{
  "code": 0,
  "message": "success",
  "data": {
    "merchantNo": "商户号",
    "orderNo": "商户订单号",
    "seqId": "退款请求流水号",
    "reqDate": "退款请求日期",
    "paySeqId": "原支付请求流水号",
    "payReqDate": "原支付请求日期",
    "payUniqueId": "原支付全局唯一流水号",
    "refundStartDate": "退款发生日期",
    "refundStartTime": "退款发生时间",
    "refundFinishTime": "退款完成时间",
    "refundStatus": 退款状态,
    "refundAmount": 退款金额, // （元）
    "realRefundAmount": 实际退款金额, // （元）
    "totalRefAmount": "原交易累计退款金额", // （元）
    "totalRefFeeAmount": "原交易累计退款手续费金额", // （元）
    "refCount": "累计退款次数"
  }
}
```

### 5.2 data响应参数说明


|                     |            |                             |
| ------------------- | ---------- | --------------------------- |
| 参数名                 | 类型         | 描述                          |
| `merchantNo`        | String     | 商户号                         |
| `orderNo`           | String     | 商户订单号                       |
| `seqId`             | String     | 退款请求流水号                     |
| `reqDate`           | Date       | 退款请求日期                      |
| `paySeqId`          | String     | 原支付请求流水号                    |
| `payReqDate`        | String     | 原支付请求日期                     |
| `payUniqueId`       | String     | 原支付全局唯一流水号                  |
| `refundStartDate`   | String     | 退款发生日期                      |
| `refundStartTime`   | Date       | 退款发生时间                      |
| `refundFinishTime`  | Date       | 退款完成时间                      |
| `refundStatus`      | Integer    | 退款状态：`枚举见：refundStatusEnum` |
| `refundAmount`      | BigDecimal | 退款金额（元）                     |
| `realRefundAmount`  | BigDecimal | 实际退款金额（元）                   |
| `totalRefAmount`    | String     | 原交易累计退款金额（元）                |
| `totalRefFeeAmount` | String     | 原交易累计退款手续费金额（元）             |
| `refCount`          | String     | 累计退款次数                      |


## 6.枚举值

### `refundStatusEnum`退款状态


|     |      |
| --- | ---- |
| 枚举值 | 描述   |
| 1   | 退款中  |
| 2   | 退款成功 |
| 3   | 退款失败 |
