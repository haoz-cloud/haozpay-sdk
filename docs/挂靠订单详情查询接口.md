## 1. 接口概述

该接口供商户查询指定挂靠订单的完整详情，包含订单基础信息、支付信息、交易确认记录、退款信息及分账列表等全维度数据，请求需进行签名验签。

---

## 2. 接口信息


| **项目** | **内容**                              |
| ------ | ----------------------------------- |
| 请求路径   | `pay-core/payment/queryOrderDetail` |
| 请求方式   | POST                                |
| 数据格式   | application/json                    |
| 签名验签   | 需要                                  |


---

## 3. 请求参数

### 3.1 顶层公共参数


| **参数名**    | **类型** | **必填** | **说明**            |
| ---------- | ------ | ------ | ----------------- |
| merchantNo | String | 是      | 皓臻支付分配的**商户号**    |
| timestamp  | Long   | 是      | 请求时间戳，**毫秒**      |
| bizBody    | String | 是      | 业务参数，**JSON 字符串** |
| sign       | String | 是      | 签名字符串             |


### 3.2 业务参数（bizBody 结构体）

表格


| **参数名** | **类型** | **必填** | **示例值**       | **说明**  |
| ------- | ------ | ------ | ------------- | ------- |
| orderNo | String | 是      | "ORDER123456" | 商户系统订单号 |


### 3.3 请求示例

```
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"orderNo\":\"ORDER123456\"}",
  "sign": "generated_sign_string"
}

```

---

## 4. 返回结果

### 4.1 统一响应结构

```
{
  "code": 0,
  "message": "success",
  "data": {
    "hostOrderInfo": {},
    "payInfo": {},
    "tradeConfirmRecord": {},
    "refundInfo": {},
    "refundDetails": [],
    "splitSettlementList": []
  }
}

```

### 4.2 顶层响应字段


| **参数名** | **类型**  | **说明**                |
| ------- | ------- | --------------------- |
| code    | Integer | 响应码：**0 = 成功**，非 0 失败 |
| message | String  | 响应描述 / 错误信息           |
| data    | Object  | 订单详情数据，成功时返回          |


### 4.3 data 节点核心参数


| **参数名**             | **类型** | **描述** |
| ------------------- | ------ | ------ |
| hostOrderInfo       | Object | 挂靠订单详情 |
| payInfo             | Object | 支付订单详情 |
| tradeConfirmRecord  | Object | 交易确认记录 |
| refundInfo          | Object | 退款主单   |
| refundDetails       | List   | 退款子单列表 |
| splitSettlementList | List   | 分账列表   |
