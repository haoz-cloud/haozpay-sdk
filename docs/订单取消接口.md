## 1. 接口说明

用于商户向皓臻支付平台提交订单取消请求，取消未支付或符合取消条件的聚合支付订单。

订单取消回调同统一下单接口回调返回。

### 2. 请求信息

- **请求地址**：`pay-core/payment/cancel`
- **请求方式**：POST
- **签名验签：**需要

### 3. 请求参数

#### 3.1 基础参数


|              |        |     |             |
| ------------ | ------ | --- | ----------- |
| 参数名          | 类型     | 必填  | 描述          |
| `merchantNo` | String | 是   | 商户编号        |
| `timestamp`  | Long   | 是   | 时间戳（毫秒）     |
| `bizBody`    | String | 是   | 业务参数JSON字符串 |
| `sign`       | String | 是   | 签名值         |


#### 3.2 业务参数（bizBody内容）


|                |        |     |             |       |
| -------------- | ------ | --- | ----------- | ----- |
| 参数名            | 类型     | 必填  | 示例值         | 描述    |
| `orderNo`      | String | 是   | ORDER123456 | 商户订单号 |
| `cancelReason` | String | 否   | 用户取消        | 取消原因  |


### 4. 请求示例

```JSON
{
  "merchantNo": "HZ1971294971928846336",
  "timestamp": 1717662987000,
  "bizBody": "{\"orderNo\":\"ORDER123456\",\"cancelReason\":\"用户取消\"}",
  "sign": "签名值"
}
```

### 5. 返回结果

#### 5.1 响应格式

```JSON
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

#### 5.2 响应参数说明

- `code`：响应状态码（0表示成功，非0表示失败）
- `message`：响应信息描述
- `data`：业务响应数据（订单取消成功时返回空对象）
