## 一、接口基本信息


|      |                                  |
| ---- | -------------------------------- |
| 项目   | 说明                               |
| 接口地址 | `pay-core/account/withdraw`      |
| 请求方法 | `POST`                           |
| 接口说明 | 商户账户提现接口，用于发起提现申请，系统自动关联当前登录商户信息 |
| 数据格式 | 请求/响应均为 `application/json`       |
| 认证要求 | 是（需登录态，系统自动获取当前商户号）              |


## 二、请求参数


|                  |            |      |                                   |
| ---------------- | ---------- | ---- | --------------------------------- |
| 字段名              | 类型         | 是否必填 | 说明                                |
| payChannel       | String     | 是    | 支付渠道 默认：HFDG                      |
| withdrawAmount   | BigDecimal | 是    | 提现金额，单位：元                         |
| intoAcctDateType | String     | 是    | 到账日期类型 `枚举见：intoAcctDateTypeEnum` |
| remark           | String     | 否    | 提现备注信息，长度建议不超过50字                 |


### 三、请求示例

```JSON
{
  "payChannel": "HFDG",
  "withdrawAmount": 100.00,
  "intoAcctDateType": "D0",
  "remark": "商户提现"
}
```

## 四、响应示例

### 成功响应

```JSON
{
  "code": 0,
  "message": "成功",
  "data": {}
}
```

### 失败响应（示例）

```JSON
{
  "code": 400,
  "message": "账户余额不足",
  "data": null
}
```

### 响应字段说明


|         |         |                    |
| ------- | ------- | ------------------ |
| 字段名     | 类型      | 说明                 |
| code    | Integer | 响应码：0表示请求成功，非0表示失败 |
| message | String  | 响应描述信息，失败时返回具体原因   |
| data    | Object  | 业务数据               |


## 五、枚举值

### `intoAcctDateTypeEnum`到账日期类型


|     |                      |
| --- | -------------------- |
| 枚举值 | 描述                   |
| D0  | 当日到账；当日交易资金当天可取现到账；  |
| T1  | 次工作日到账；              |
| D1  | 次自然日到账；              |
| DM  | 当日到账；到账资金不包括当天的交易资金; |
