### 1 基本信息


| **项目** | **内容**                                       |
| ------ | -------------------------------------------- |
| 接口地址   | `pay-core/merchant/split/reverseSplitRefund` |
| 请求方法   | POST                                         |
| 接口说明   | 撤销已完成的分账操作并退款                                |
| 是否需要认证 | 是（需签名验证）                                     |


### 2 请求参数


| **字段名**      | **类型** | **是否必填** | **说明** | **示例值**          |
| ------------ | ------ | -------- | ------ | ---------------- |
| merchantNo   | String | 是        | 商户号    | HZ123456789      |
| orderNo      | String | 是        | 原支付订单号 | ORDER20251226001 |
| cancelReason | String | 否        | 取消原因   | 用户申请退款           |


### 3 请求示例

```
{
  "merchantNo": "HZ123456789",
  "orderNo": "ORDER20251226001",
  "cancelReason": "用户申请退款"
}

```

### 4 响应参数

#### 4.1 顶层参数


| **字段名** | **类型**  | **说明**                | **示例值** |
| ------- | ------- | --------------------- | ------- |
| code    | Integer | 响应码：0 表示请求成功，非 0 表示失败 | 0       |
| message | String  | 响应描述信息，失败时返回具体原因      | 成功      |
| data    | Object  | 业务数据，失败时为 null        | 详见下方    |


#### 4.2 data 子参数


| **字段名**               | **类型**     | **说明**         | **示例值**          |
| --------------------- | ---------- | -------------- | ---------------- |
| orderNo               | String     | 商户订单号          | ORDER20251226001 |
| totalRefundAmount     | BigDecimal | 撤销分账退款总金额，单位：元 | 100.00           |
| merchantRefundDetails | List       | 退款商户明细列表       | 详见下方             |


#### 4.3 merchantRefundDetails 子参数


| **字段名**    | **类型** | **说明**    | **示例值**     |
| ---------- | ------ | --------- | ----------- |
| divAmt     | String | 退款金额，单位：元 | 80.00       |
| merchantNo | String | 商户号       | HZ987654321 |


### 5 响应示例

#### 5.1 成功响应

```
{
  "code": 0,
  "message": "成功",
  "data": {
    "orderNo": "ORDER20251226001",
    "totalRefundAmount": 100.00,
    "merchantRefundDetails": [
      {
        "divAmt": "80.00",
        "merchantNo": "HZ987654321"
      },
      {
        "divAmt": "20.00",
        "merchantNo": "HZU567890123"
      }
    ]
  }
}

```

#### 5.2 失败响应

```
{
  "code": 400,
  "message": "订单不存在或未完成分账",
  "data": null
}
```
