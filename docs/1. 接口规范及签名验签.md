## 四、接口签名说明

### （一）签名规范

商户端的平台业务系统和皓臻支付系统生成各自 RSA 公私钥，生成密钥后交换各自 RSA 公钥。

- 商户需要生成一对公私钥，将公钥配置到皓臻支付平台商户管理控台→账户管理→开发信息管理→商户签名公钥中，私钥配置在商户端的平台业务系统中（请妥善保管请勿泄露）。
- 商户端平台业务系统也需要将皓臻支付平台商户管理控台→账户管理→开发信息管理→皓臻支付公钥配置到商户业务系统中。

生成公私钥说明：签名算法为 SHA256WithRSA，算法不一致会导致验签失败。


### （三）签名算法

#### 1. 请求接口签名

> :warning: **重要**：bizBody 参数需要展开参与签名

##### 第一步：bizBody 参数展开

bizBody 内的业务参数需要取出，与 merchantNo、timestamp 同级排列后参与签名。

示例：

```
请求参数：
{
  "bizBody": {
    "orderAmount": "0.01",
    "orderTitle": "Test Order",
    "notifyUrl": "https://xxx.com/notify"
  },
  "merchantNo": "HZ2018236605422157824",
  "timestamp": "1772698873793",
  "sign": "..."
}

展平后参与签名的参数：
{
  "orderAmount": "0.01",
  "orderTitle": "Test Order",
  "notifyUrl": "https://xxx.com/notify",
  "merchantNo": "HZ2018236605422157824",
  "timestamp": "1772698873793"
}

```

##### 第二步：参数处理

请求的业务接口，除开 sign 参数，其余参数进行字典序升序排列，如果对应的参数值为 null，则略过该参数，最终生成形如 "参数 A=A 参数值 & 参数 B=B 参数值…… 参数 N=N 参数值" 的单行字符串文本 paramsStr。

##### 第三步：SHA256 摘要

对 paramsStr 进行 SHA256 摘要加密，得到 sha256ParamsStr（64 位十六进制字符串）。

##### 第四步：RSA 加密

对 sha256ParamsStr 使用 商户私钥 进行 RSA 加密，得到 encryptParamsStr。

##### 第五步：Base64 编码

将 encryptParamsStr 进行 Base64 编码，回填至 sign 字段中，之后进行接口请求。

###### （1）Java 示例代码

```
import cn.hutool.crypto.SecureUtil;
import cn.hutool.crypto.KeyType;
import cn.hutool.crypto.asymmetric.RSA;
import com.alibaba.fastjson.JSON;
import com.alibaba.fastjson.JSONObject;
import java.util.*;

Map<String, String> paramsMap = new HashMap<>();

// ⚠️ 第一步：从 bizBody 展开（重要：bizBody 参数需要取出）
String bizBodyJson = "{\"orderAmount\":\"0.01\",\"orderTitle\":\"Test Order\",\"notifyUrl\":\"https://www.baidu.com\",\"orderNo\":\"P0123456789101\"}"; // 实际使用时从请求中获取
JSONObject bizBody = JSON.parseObject(bizBodyJson);
for (Map.Entry<String, Object> entry : bizBody.entrySet()) {
    if (entry.getValue() != null) {
        paramsMap.put(entry.getKey(), String.valueOf(entry.getValue()));
    }
}

// 添加公共参数
paramsMap.put("merchantNo", "HZ1001");
paramsMap.put("timestamp", "1772698873793");

// 第二步：参数名ASCII码从小到大排序（字典序）；
// 如果参数的值为空不参与签名；
// 签名串
StringBuilder sb = new StringBuilder();
paramsMap.keySet().stream().sorted().forEach(key -> {
    String value = paramsMap.get(key);
    if (value != null && !value.isEmpty()) {
        sb.append(key).append("=").append(value).append("&");
    }
});
sb.deleteCharAt(sb.length() - 1);

// 第三步：进行sha256摘要签名（得到64位十六进制字符串）
String sha256Hex = SecureUtil.sha256(sb.toString());

// 第四步：使用商户私钥进行RSA加密（注意：不是直接sha256就完了，需要RSA加密）
RSA rsa = new RSA(privateKey, null);
String encryptedSign = rsa.encryptBase64(sha256Hex, KeyType.PrivateKey);

```

###### （2）Python 示例代码

```
import hashlib
import base64
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import padding
from cryptography.hazmat.backends import default_backend

def sign(params: dict, private_key_pem: str) -> str:
    # 1. 参数展平：将 bizBody 内容取出
    sign_params = {}
    biz_body = params.get('bizBody', {})
    for key, value in biz_body.items():
        if value is not None:
            sign_params[key] = str(value)

    # 添加公共参数
    if 'merchantNo' in params:
        sign_params['merchantNo'] = str(params['merchantNo'])
    if 'timestamp' in params:
        sign_params['timestamp'] = str(params['timestamp'])

    # 2. 字典序排列并拼接
    sorted_items = sorted(sign_params.items())
    sign_string = "&".join([f"{k}={v}" for k, v in sorted_items])

    # 3. SHA-256 hex
    sha256_hex = hashlib.sha256(sign_string.encode('utf-8')).hexdigest()

    # 4. RSA 私钥加密
    private_key = serialization.load_pem_private_key(
        private_key_pem.encode('utf-8'),
        password=None,
        backend=default_backend()
    )
    signature = private_key.sign(
        sha256_hex.encode('utf-8'),
        padding.PKCS1v15(),
        hashes.SHA256()
    )

    # 5. Base64 编码
    return base64.b64encode(signature).decode('utf-8')

```

###### （3）Node.js 示例代码

```
const crypto = require("crypto");

function generateSign(params, privateKey) {
    // 1. 参数展平：将 bizBody 内容取出
    const signParams = {};

    if (params.bizBody && typeof params.bizBody === 'object') {
        Object.keys(params.bizBody).forEach(key => {
            const value = params.bizBody[key];
            if (value !== null && value !== undefined) {
                signParams[key] = String(value);
            }
        });
    }

    // 添加公共参数
    if (params.merchantNo) signParams.merchantNo = String(params.merchantNo);
    if (params.timestamp) signParams.timestamp = String(params.timestamp);

    // 2. 字典序排列并拼接
    const sortedKeys = Object.keys(signParams).sort();
    const signString = sortedKeys.map(key => `${key}=${signParams[key]}`).join('&');

    // 3. SHA-256 hex
    const sha256Hex = crypto.createHash('sha256').update(signString, 'utf8').digest('hex');

    // 4. RSA 私钥加密
    const encrypted = crypto.privateEncrypt(
        { key: privateKey, padding: crypto.constants.RSA_PKCS1_PADDING },
        Buffer.from(sha256Hex, 'utf8')
    );

    // 5. Base64 编码
    return encrypted.toString('base64');
}

```

#### 2. 异步通知验签

步骤请参考请求接口加签步骤（需要注意的是 回调的签名是皓臻支付通过平台密钥进行加密的，故而商户侧应用需要使用皓臻支付平台公钥进行解密），再进行对比签名是否一致，不一致则商户业务系统不处理该请求，可能为三方恶意用户伪造的请求。

```
// 1. 提取回调参数
String sign = notifyData.getSign();
Map<String, String> params = notifyData.getParams();

// 2. 拼接签名串（同签名流程）
String signString = buildSignString(params);

// 3. SHA-256
String sha256Hex = SecureUtil.sha256(signString);

// 4. 用平台公钥解密签名
RSA rsa = new RSA(null, platformPublicKey);
byte[] decrypted = rsa.decryptBase64(sign, KeyType.PublicKey);

// 5. 比对
if (sha256Hex.equals(new String(decrypted))) {
    // 验签成功
} else {
    // 验签失败
}

```

## 五、常见问题 FAQ

### Q1: 签名一直失败怎么办？

**检查清单**：

1. :check_mark_button: bizBody 字段是否已展平（不是整体字符串）
2. :check_mark_button: SHA-256 后是 64 位 hex 字符串，不是 binary
3. :check_mark_button: RSA 加密的是 hash 值，不是原字符串
4. :check_mark_button: 公私钥是否为一对（用 OpenSSL 验证）
5. :check_mark_button: 私钥格式是否为 PKCS#8

### Q2: 如何验证公私钥是否匹配？

```
# 从私钥导出公钥
openssl rsa -in private.pem -pubout -out pub_from_private.pem

# 对比 modulus（两者应相同）
openssl rsa -modulus -pubin -in pub_from_private.pem -modulus -noout
openssl rsa -modulus -pubin -in uploaded_public_key.pem -modulus -noout

```

### Q3: 商户公钥上传后多久生效？

通常即时生效，如遇延迟请稍等后重试。
